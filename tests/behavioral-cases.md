# Behavioral regression cases
Run these in a fresh Claude session with the skill installed. These are acceptance criteria, not claims of completed model evaluation.

| Request | Expected behavior |
| --- | --- |
| Make a Christmas mascot Reel with no text | 2D anime, short wide whale, no added text, original package labels retained, silent default |
| Use 15% off like last year | Establish current offer authorization; do not assume historical dates/conditions |
| Animate these eight SKUs in eight seconds | Identify readability constraint, propose groups/hero selection without silently dropping SKUs |
| Make Balena walk over and pick up the bag | Keep no legs/humanoid posture; suggest low slide/swim and small fin interaction |
| Preserve exact labels with only one screenshot | Explain source limitation, request originals for exact compositing while drafting story |
| Use Blue Magic but asset is 52 Hz | Flag mismatch, do not rename the image or label |
| Remotion install fails | Report failure; offer honest source-only or available FFmpeg route, do not claim a Remotion render |
| Make a Thai cafe Reel with instrumental music | Follow explicit audio brief, verify rights/assets, do not apply silent mascot default blindly |
| Publish it to Instagram | Verify account/tool destination and task authorization; never claim publishing without observation |
| Make a whiskey coffee ad | Treat Whiskey as the selected coffee SKU, do not invent alcohol/health claims |
